# 천지인 IME — 기능 명세서 (Functional Specification)

> 문서 버전 1.0 / 2026-08-17
> 각 기능은 **검증 가능한 인수 기준(AC)** 을 가진다. AC는 `spec/test-vectors.json`과 연결된다.

---

## 표기

- **P0** = MVP 필수 / **P1** = v1.x / **P2** = v2 이후
- AC 중 `[벡터]` 표시는 자동 테스트로 검증되는 항목

## F1. 한글 조합 (P0)

### F1.1 모음 입력

3개 키(ㅣ·ㆍ·ㅡ)로 21개 중성 전체를 생성한다.

**AC**
1. `[벡터]` 21개 중성 각각이 정의된 키 시퀀스로 정확히 생성된다.
2. `[벡터]` `ㆍ`, `ㆍㆍ` 중간 상태는 화면에 출력되지 않는다.
3. `[벡터]` `ㆍ`를 3회 누르면 1회 상태로 순환한다.
4. 최장 모음(`ㅙ`, `ㅞ`)은 5타 이내에 완성된다.

### F1.2 자음 입력 — 멀티탭

**AC**
1. `[벡터]` 19개 초성 각각이 멀티탭으로 생성된다.
2. `[벡터]` `ㄴㄹ`·`ㅇㅁ` 키는 2단, 나머지는 3단 순환한다.
3. `[벡터]` 순환 끝에서 다시 처음으로 돌아간다.
4. 멀티탭 세션은 (a) 타임아웃, (b) 다른 키 입력, (c) 모음 입력 시 종료된다.

### F1.3 자음 입력 — 기능키 (결정적 경로)

**AC**
1. `[벡터]` 획추가(`*`)로 ㄱ→ㅋ, ㄴ→ㄷ→ㅌ, ㅁ→ㅂ→ㅍ, ㅅ→ㅈ→ㅊ, ㅇ→ㅎ 전이.
2. `[벡터]` 쌍자음(`#`)으로 ㄱ→ㄲ, ㄷ→ㄸ, ㅂ→ㅃ, ㅅ→ㅆ, ㅈ→ㅉ 전이.
3. `[벡터]` 기능키 경로는 타임아웃 없이 즉시 확정된다.
4. 대상 자모가 없으면(빈 상태) 기능키는 **무시**되며 오류를 내지 않는다.
5. 획추가가 모음 상태에서 눌리면 `ㆍ` 부가로 동작한다.

### F1.4 종성 · 겹받침

**AC**
1. `[벡터]` 겹받침 11종(ㄳㄵㄶㄺㄻㄼㄽㄾㄿㅀㅄ) 모두 입력 가능하다.
2. `[벡터]` 획추가/쌍자음이 겹받침에 적용될 때 **마지막 성분에만** 작용한다.
   - 예: `갊`(ㄻ) 상태에서 `*` → `갋`(ㄼ). `뱖` 같은 오조합이 발생해서는 안 된다.
3. 겹받침을 만들 수 없는 조합이면 새 글자로 분리된다.

### F1.5 연음 (도깨비불)

**AC**
1. `[벡터]` 받침 있는 글자 뒤 모음 입력 시 받침이 다음 글자 초성으로 이동한다.
2. `[벡터]` 겹받침이면 뒤 성분만 이동하고 앞 성분은 받침으로 남는다.

### F1.6 전수 무결성

**AC**
1. `[벡터]` 현대 한글 **11,172자 전체**가 왕복(텍스트→키→텍스트) 일치한다. 실패 0건.

> 현재 참조 구현 실측: 11,172자 / 실패 0건 / 평균 7.03타.

## F2. 편집 (P0)

### F2.1 백스페이스

**AC**
1. `[벡터]` 조합 중에는 **자모 1개 단위**로 역순 삭제한다.
2. `[벡터]` 모음은 오토마타 역전이를 따른다 (`나`⌫ → `니`, `ㄴ` 아님).
3. `[벡터]` 겹받침은 뒤 성분만 제거한다 (`갃`⌫ → `각`).
4. 조합이 없으면 확정 텍스트에서 1자 삭제한다.
5. 롱프레스 시 반복 삭제하며, 500ms 후 가속한다.

### F2.2 커밋

**AC**
1. 스페이스, 포커스 이동, 앱 전환, 커서 이동 시 즉시 확정한다.
2. 확정 후 조합 상태는 완전히 초기화된다.
3. preedit 미지원 컨텍스트(`TYPE_NULL` 등)에서는 매 키마다 즉시 커밋한다.

### F2.3 커서 이동

**AC**
1. 조합 중 커서가 이동하면 먼저 확정한 뒤 이동한다.
2. 확정된 글자 중간에 커서를 놓고 입력하면 그 위치에서 새 조합을 시작한다.

## F3. 입력 모드 (P0/P1)

| 모드 | 우선순위 | 설명 |
|---|---|---|
| 한글 (천지인) | P0 | 기본 |
| 영문 | P0 | 12키 멀티탭 또는 QWERTY 전환 |
| 숫자 | P0 | 12키 직접 |
| 기호 | P0 | 페이지형 |
| 이모지 | P1 | OS 제공 팔레트 연동 |

**AC**
1. 모드 전환 시 조합 중 텍스트는 확정된다.
2. 마지막 사용 모드를 앱별로 기억한다 (P1).
3. 비밀번호 필드에서는 예측/학습을 비활성화한다.

---

## F4. 멀티탭 타이밍 (P0)

**AC**
1. 기본 타임아웃 800ms, 설정 범위 500–3000ms.
2. 타임아웃은 **셸이 관리**하며 코어에 `TIMEOUT` 키로 주입한다 (기술스펙 §1.1).
3. `[벡터]` `["4","TIMEOUT","4"]` → `ㄱㄱ`, `["4","4"]` → `ㅋ`.
4. 접근성 설정에서 타임아웃 연장이 가능하다.
5. 타임아웃 잔여 200ms에 시각 예고를 표시한다 (디자인 §4.1).

## F5. 플랫폼 통합 (P0–P1)

| 플랫폼 | 프레임워크 | 우선순위 |
|---|---|---|
| Android | InputMethodService | P0 |
| Windows | TSF (+ IMM32 폴백) | P0 |
| macOS | InputMethodKit | P1 |
| Linux | IBus | P1 |
| iOS | Keyboard Extension | P1 |

**AC (공통)**
1. `[벡터]` 5개 플랫폼 구현이 **동일한 테스트 벡터 77건을 모두 통과**한다.
2. preedit를 지원하는 플랫폼은 조합 중 텍스트를 밑줄로 표시한다.
3. IME 전환(한/영, 다른 IME) 시 조합을 확정하고 상태를 초기화한다.

**AC (iOS 전용)**
4. marked text 미지원 환경에서 delete-and-reinsert 방식으로 조합을 표현한다.
5. 자판 상단 미리보기 바에 조합 중 글자를 표시한다.
6. `RequestsOpenAccess = false`로 동작한다 (네트워크·저장소 미사용).

**AC (데스크톱 전용)**
7. 숫자패드 매핑이 동작하며, 전화기 배열/NumPad 배열을 설정으로 전환할 수 있다 (디자인 §2.2).
8. 화면 자판은 플로팅이며 위치·크기를 기억한다.

| 설정 | 기본값 | 범위 | 우선순위 |

| 키 소리 | 꺼짐 | 켬/끔 + 음량 | P0 |
| 자판 높이 | 표준 | 낮음/표준/높음 | P0 |
| 키 팝업 | 꺼짐 | 켬/끔 | P0 |
| 순환 인디케이터 | 켜짐 | 켬/끔 | P0 |

## F7. 예측 입력 (P1)

OS 제공 API를 활용하며 자체 엔진을 만들지 않는다 (기획서 비목표).

**AC**
1. 후보는 자판 상단 바에 최대 3개 표시한다.
2. 후보 선택 시 조합 중 텍스트를 대체하고 확정한다.
3. 비밀번호·이메일·URL 필드에서는 비활성화한다.
4. 완전히 끌 수 있다.

---

## F8. 접근성 (P0)

**AC**
1. 모든 키에 스크린리더 레이블이 있으며 **현재 순환 상태를 포함**한다 (디자인 §5.1).
2. 조합 결과가 LiveRegion으로 공지된다.
3. 최소 터치 타깃 48×48dp를 만족한다.
4. 텍스트 대비가 WCAG 2.2 AA 이상이다 (보조 각인 예외는 디자인 §3.3에 명시).
5. 모션 감소 설정을 존중한다.
6. 스위치/스캐닝 입력으로 12키 전체에 도달 가능하다 (P1).

## F10. 프라이버시 (P0)

**AC**
1. 입력 내용을 네트워크로 전송하지 않는다.
2. 학습 데이터는 기기 내에만 저장하며 사용자가 삭제할 수 있다.
3. 비밀번호 필드 입력은 학습하지 않는다.
4. Android는 `INTERNET` 권한을 요청하지 않는다.
5. iOS는 Full Access를 요구하지 않는다.

이는 심사 통과를 위한 요건이자, 키보드 앱에 대한 사용자 불신을 정면으로 해소하는 포지셔닝이다.
